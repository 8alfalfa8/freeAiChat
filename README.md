本リポジトリ（freeAiChat）は、マルチLLM対応AIチャットアプリです。
>また、本アプリは **Groq（LPU）を利用することで、LLM推論コストを完全無料で運用できます。**
OpenAI / Groq を環境変数で切り替え可能なため、用途に応じて「高速・無料」「高品質モデル」を柔軟に選択できます。


◆ ユースケース
* コールセンターやサポートデスクの自動化
* 社内ヘルプデスク（IT・人事・総務）の自動応答
* ナレッジベース連携型FAQチャットボット
* 営業・提案支援チャット（CRM連携）
